# Rent5 — 중개사 없이 임대인 ↔ 임차인이 직접 계약

rent3 · rent4 를 참고해 **가장 단순하게** 다시 만든 직거래 계약 시스템입니다.
파이썬 파일 몇 개와 정적 화면만 있고, 본체는 이 **독립 폴더**(`rent5/`)에 있습니다.
같은 코드를 두 가지로 씁니다: ① 혼자 실행(`py rent5/run.py`) ② 서버의 게이트웨이에 얹기(`apps/rent5/app.py` 어댑터가 `/rent5/` 로 연결).

## 실행

```bash
pip install -r rent5/requirements.txt
py rent5/run.py                 # 혼자 실행: http://127.0.0.1:8050  (--port, --host 로 바꿈)
py run.py                       # 플랫폼 전체(게이트웨이): http://localhost:8080/rent5/
py -m unittest discover -s rent5/tests   # 저장소 루트에서 — 테스트 37개
```

| | 혼자 실행 (`rent5/run.py`) | 게이트웨이 (`run.py`, 서버) |
|---|---|---|
| 화면 | `/` | `/rent5/` |
| API | `/api/...` | `/api/rent5/...` |
| 데이터 기본 위치 | `rent5/data/` | `data/rent5_pool/` |

| 환경변수 | 뜻 |
|---|---|
| `RENT5_DATA_DIR` | 데이터 폴더 (위 기본값을 바꿈) |
| `RENT5_SECRET` | 로그인 서명 비밀키. 없으면 데이터 폴더의 `secret.key` 를 처음 한 번 무작위로 만든다 |
| `PORT`, `HOST` | 혼자 실행(`rent5/run.py`) 기본값 |

## 사람의 흐름

```
매물 목록(index)에서 [계약 신청] → 임대인에게 전화가 걸리고, 옆에 [예약] 버튼이 열린다
→ 현장 방문 · 매물 확인 → [예약] (로그인 필요 — 로그인하면 같은 매물로 돌아온다)
→ 계약방(임대인 · 임차인이 함께 쓰는 카카오톡식 대화창) 이 열린다
→ 임대인 · 매물 정보와 임차인(회원가입) 정보가 말풍선 카드로 뜨고, 각자 상대 것만 확인 체크
→ 임대인이 등기부등본 열람(스마트폰) → 대면으로 보여 주고 선순위 조건을 올림 → 임차인이 "등기부등본 확인했음" 체크
→ 임대인이 계약금(보증금의 10%) 계좌 알림 → 임차인이 송금했다고 알림 → 계약 종료 (확인서 인쇄 · PDF)
```

- **회원 구분이 없습니다.** 누구나 매물을 올리고(임대인), 남의 매물을 예약합니다(임차인). 내 매물은 예약할 수 없습니다.
- **예약된 매물은 다른 사람이 고를 수 없습니다.** 목록에는 "예약됨"으로 남고 문의 번호는 가려집니다. 어느 쪽이든 종료 전에 취소하면 매물이 다시 열립니다. 한 사람이 동시에 예약할 수 있는 매물은 3개까지입니다.
- 단계마다 한 줄씩 대화창에 말풍선이 남고, 일반 대화도 같은 창에서 합니다. 상대가 하면 3초 안에 화면이 바뀝니다.
- 체크 권한: 임대인 정보 확인 · 등기부등본 확인 · 송금은 **임차인만**, 임차인 정보 확인 · 등기부 열람 · 계좌 알림은 **임대인만** 할 수 있습니다.
- 돈은 두 사람이 **직접 송금**합니다. 프로그램은 임차인이 "송금했다"고 알린 기록만 남기며 은행 거래를 확인하지 않습니다.
- 로그인 뒤 돌아갈 곳은 `?next=` 로만 전달합니다 (같은 폴더의 `.html` 상대 경로만 허용).

## 계약 단계 (`flow.py`)

| 상태 | 누가 | 하는 일 |
|---|---|---|
| `reserved` | 임차인 | 예약 → 매물 `reserved`. 임차인은 임대인 · 매물 정보를, 임대인은 임차인 정보를 서로 확인 (둘 다 하면 다음 단계) |
| `info_ok` | 임대인 | 등기부등본 열람 → 소유자 일치 · 압류 없음 · 선순위 근저당 금액 · 메모를 올림 |
| `registry_shown` | 임차인 | "등기부등본 확인했음" |
| `registry_ok` | 임대인 | 계약금(보증금의 10%) 송금 계좌 알림. 예금주가 임대인 이름과 다르면 경고 문구가 붙음 |
| `account_sent` | 임차인 | "송금했습니다" → 매물 `closed`, 확인서 발급 (`final_hash`, SHA-256) |
| `completed` | — | 계약 종료. 대화는 계속 가능 |
| `cancelled` | 어느 쪽이든 | 종료 **전에만** 가능. 매물이 다시 열림 |

이전의 조건 제시 · 서명 방식(`requested` … `active`) 계약은 기록으로만 남고, 진행 중이던 것은 취소만 할 수 있습니다.

월세 30만 원 또는 보증금 6천만 원을 넘으면 계약서와 화면에 임대차 신고(30일 이내) 안내가 붙습니다.

## 파일

```
rent5/
├─ app.py          build_router(API, 경로에 /api 없음) · create_app(혼자 실행용: /api + static/ 화면)
├─ flow.py         계약 단계 규칙 · 지문 · 화면용 변환
├─ listings.py     매물 올리기 · 공개 목록 · 내리기
├─ security.py     비밀번호 해시 · 토큰 · 로그인 잠금 · 입력 검사
├─ store.py        data/<이름>.json 저장 (원자적 쓰기, 밖에서 바뀌면 다시 읽기)
├─ run.py          혼자 실행
├─ scripts/set_password.py   운영자가 회원 비밀번호 재설정
├─ static/         index · login · signup · my · contract · doc (.html + .js) , app.js , style.css
└─ tests/          test_rent5.py (본체) · test_gateway.py (게이트웨이로 올려서 끝까지)
apps/rent5/app.py  게이트웨이 어댑터 — rent5 를 /rent5/ · /api/rent5 에 자동 마운트 (핵심 로직 없음)
```

## 보안 설계

- 비밀번호: PBKDF2-SHA256(20만 회) + 회원별 salt. 원문 저장 없음. 8자 이상, 같은 글자 반복 · 아이디와 같은 값 금지.
- 로그인 토큰: 서버 비밀키로 서명, 12시간. **비밀번호를 바꾸면 이전 토큰이 즉시 무효**(`pw_ver`).
- 로그인 실패 5번이면 (IP + 아이디) 10분 잠금. 없는 아이디와 틀린 비밀번호는 같은 메시지와 같은 계산 시간.
- 계약은 **당사자만** 봅니다. 당사자가 아니면 "없는 계약"(404)으로 답합니다.
- 공개 매물에는 회원 이름 · 아이디 · 가입 번호가 나가지 않고, 임대인이 직접 적은 문의 번호만 나갑니다.
- 주민등록번호 모양은 모든 입력 칸에서 거부합니다. 생년월일만 받습니다.
- CSP `script-src 'self'; style-src 'self'` — 화면에 인라인 스크립트 · 스타일이 없습니다. 화면에 넣는 모든 값은 이스케이프합니다.
  혼자 실행할 때는 응답 헤더로, 게이트웨이에서는 각 페이지의 `<meta>` 로 적용합니다 (게이트웨이는 앱별 헤더를 붙일 수 없어서). 그래서 게이트웨이에서는 `X-Frame-Options`(다른 사이트에 끼워 넣기 방지)는 빠집니다.
- `data/` 는 `.gitignore` 로 제외됩니다 (회원 정보 · 계약 · 비밀키).

## 운영

- **비밀번호를 잊은 회원**: `py rent5/scripts/set_password.py <아이디>` (서버에서, 새 비밀번호를 두 번 입력). 그 회원의 기존 로그인은 모두 끝납니다. 이메일 · 문자 재설정은 두지 않았습니다.
- **백업**: `data/` 폴더를 통째로 복사하면 됩니다 (사람이 읽을 수 있는 JSON).
- **서버(게이트웨이) 배포**: `main` 에 합치면 기존 Coolify 빌드(`python run.py`)가 `apps/rent5` 를 찾아 `/rent5/` 로 띄웁니다. 별도 설정은 필요 없지만 **운영에서는 꼭**:
  - `data/rent5_pool/` 을 컨테이너 밖 **영구 저장소(볼륨)** 에 연결하세요. 안 하면 재배포할 때마다 회원 · 매물 · 계약이 사라집니다. 이 폴더는 이미지에서 제외돼 있습니다.
  - `RENT5_SECRET` 환경변수를 지정하세요 (없으면 데이터 폴더에 만든 `secret.key` 를 쓰는데, 폴더가 영구가 아니면 재배포 때마다 모두 로그아웃됩니다).
  - Coolify 가 HTTPS 를 붙이는지 확인하세요 (로그인 토큰이 오가므로 필수).
- **혼자 서버로 띄우기**: `uvicorn rent5.app:create_app --factory --host 0.0.0.0 --port 8050` (저장소 루트에서).

## 일부러 뺀 것 (단순함을 위해)

- **구글 · 카카오 본인 확인**: rent4 에 있던 외부 인증은 뺐습니다. 지금은 아이디/비밀번호와 휴대폰 번호 입력뿐이라 **신원 확인이 약합니다.** 실제 운영 전에 필요하면 추가하세요.
- **푸시 알림**: 계약방을 열어 둔 동안만 상대 메시지가 보입니다 (3초마다 확인). 닫아 두면 알려 주지 않습니다.
- **예약 만료**: 예약한 사람이 오지 않으면 임대인이 직접 취소해야 매물이 다시 열립니다 (자동 만료 없음).
- **등기부 자동 열람 · 전자서명 인증서 · 결제**: 없습니다. 등기는 임대인이 스마트폰으로 열람해 임차인에게 보여 주고 조건을 입력하며, 임차인은 필요하면 인터넷등기소에서 직접 확인합니다. 확인서는 "각자 로그인 상태로 확인한 순서의 기록"이며, **법적 효력은 보장하지 않습니다.**
- **여러 서버 프로세스**: 한 프로세스를 전제로 합니다 (파일 저장 + 프로세스 안 잠금). 서버를 여러 대로 늘리려면 DB 로 바꿔야 합니다.
- **계약 종료 뒤 해지 · 수정**: 화면에 없습니다.
