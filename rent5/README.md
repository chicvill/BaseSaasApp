# Rent5 — 중개사 없이 임대인 ↔ 임차인이 직접 계약

rent3 · rent4 를 참고해 **가장 단순하게** 다시 만든 직거래 계약 시스템입니다.
BaseSaasApp 의 다른 앱과 섞이지 않는 **독립 폴더**이고, 파이썬 파일 몇 개와 정적 화면만 있습니다.

## 실행

```bash
pip install -r rent5/requirements.txt
py rent5/run.py                 # http://127.0.0.1:8050  (--port, --host 로 바꿈)
py -m unittest discover -s rent5/tests   # 저장소 루트에서 — 테스트 30개
```

| 환경변수 | 뜻 |
|---|---|
| `RENT5_DATA_DIR` | 데이터 폴더 (기본 `rent5/data`) |
| `RENT5_SECRET` | 로그인 서명 비밀키. 없으면 `data/secret.key` 를 처음 한 번 무작위로 만든다 |
| `PORT`, `HOST` | `run.py` 기본값 |

## 사람의 흐름

```
매물 찾기(index) → 임대인과 통화 → [계약 신청] → (비회원이면) 회원가입 → 같은 매물 신청 화면으로 복귀
→ 신청 → 임대인이 조건 제시(+등기 확인) → 임차인 서명 → 임대인 서명(계약 성립, 매물 마감)
→ 계약금 확인 → 잔금 확인(입주) → 계약서 인쇄 · PDF
```

- **회원 구분이 없습니다.** 누구나 매물을 올리고(임대인), 남의 매물에 신청합니다(임차인). 내 매물에는 신청할 수 없습니다.
- 돈은 두 사람이 **직접 송금**합니다. 프로그램은 임대인이 "받았다"고 확인한 기록만 남깁니다.
- 로그인 뒤 돌아갈 곳은 `?next=` 로만 전달합니다 (같은 폴더의 `.html` 상대 경로만 허용).

## 계약 단계 (`flow.py`)

| 상태 | 누가 | 하는 일 |
|---|---|---|
| `requested` | 임차인 | 신청 (임대인은 신청자 이름 · 번호를 봄) |
| `offered` | 임대인 | 주소 · 보증금 · 계약금 · 월세 · 입주일 · 기간 + 등기 확인(소유자 일치 · 압류 없음 · 근저당 금액). 다른 신청자는 자동 마감, 매물은 `reserved` |
| `tenant_signed` | 임차인 | 생년월일 · 현재 주소 · 비상 연락처 + 동의. 보고 있던 조건이 그 사이 바뀌었으면(`offer_hash`) 서명 거부 |
| `signed` | 임대인 | 같은 지문(`final_hash`, SHA-256)에 서명 → 계약 성립, 매물 `closed`, 계약서 발급 |
| `deposit_paid` · `active` | 임대인 | 계약금 확인 · 잔금 확인(입주) |
| `cancelled` | 어느 쪽이든 | 성립(`signed`) **전에만** 가능. 성립 뒤 해지는 두 사람이 직접 합의 |

월세 30만 원 또는 보증금 6천만 원을 넘으면 계약서와 화면에 임대차 신고(30일 이내) 안내가 붙습니다.

## 파일

```
rent5/
├─ app.py          FastAPI 앱 (create_app) · /api/... 와 static/ 화면
├─ flow.py         계약 단계 규칙 · 지문 · 화면용 변환
├─ listings.py     매물 올리기 · 공개 목록 · 내리기
├─ security.py     비밀번호 해시 · 토큰 · 로그인 잠금 · 입력 검사
├─ store.py        data/<이름>.json 저장 (원자적 쓰기, 밖에서 바뀌면 다시 읽기)
├─ run.py          실행
├─ scripts/set_password.py   운영자가 회원 비밀번호 재설정
├─ static/         index · login · signup · apply · my · contract · doc (.html + .js) , app.js , style.css
└─ tests/test_rent5.py
```

## 보안 설계

- 비밀번호: PBKDF2-SHA256(20만 회) + 회원별 salt. 원문 저장 없음. 8자 이상, 같은 글자 반복 · 아이디와 같은 값 금지.
- 로그인 토큰: 서버 비밀키로 서명, 12시간. **비밀번호를 바꾸면 이전 토큰이 즉시 무효**(`pw_ver`).
- 로그인 실패 5번이면 (IP + 아이디) 10분 잠금. 없는 아이디와 틀린 비밀번호는 같은 메시지와 같은 계산 시간.
- 계약은 **당사자만** 봅니다. 당사자가 아니면 "없는 계약"(404)으로 답합니다.
- 공개 매물에는 회원 이름 · 아이디 · 가입 번호가 나가지 않고, 임대인이 직접 적은 문의 번호만 나갑니다.
- 주민등록번호 모양은 모든 입력 칸에서 거부합니다. 생년월일만 받습니다.
- CSP `script-src 'self'; style-src 'self'` — 화면에 인라인 스크립트 · 스타일이 없습니다. 화면에 넣는 모든 값은 이스케이프합니다.
- `data/` 는 `.gitignore` 로 제외됩니다 (회원 정보 · 계약 · 비밀키).

## 운영

- **비밀번호를 잊은 회원**: `py rent5/scripts/set_password.py <아이디>` (서버에서, 새 비밀번호를 두 번 입력). 그 회원의 기존 로그인은 모두 끝납니다. 이메일 · 문자 재설정은 두지 않았습니다.
- **백업**: `data/` 폴더를 통째로 복사하면 됩니다 (사람이 읽을 수 있는 JSON).
- **배포**: `uvicorn app:create_app --factory --app-dir rent5 --host 0.0.0.0 --port 8050`. 반드시 HTTPS 뒤에 두고, `RENT5_SECRET` 과 데이터 폴더(영구 저장소)를 지정하세요.

## 일부러 뺀 것 (단순함을 위해)

- **구글 · 카카오 본인 확인**: rent4 에 있던 외부 인증은 뺐습니다. 지금은 아이디/비밀번호와 휴대폰 번호 입력뿐이라 **신원 확인이 약합니다.** 실제 운영 전에 필요하면 추가하세요.
- **채팅 · 알림**: 연락은 전화로 합니다 (신청 뒤 서로의 번호가 보입니다).
- **등기부 자동 열람 · 전자서명 인증서 · 결제**: 없습니다. 등기는 임대인이 입력하고 임차인이 인터넷등기소에서 직접 확인합니다. 서명은 "같은 지문에 각자 로그인 상태로 동의한 기록"이며, **법적 효력은 보장하지 않습니다.**
- **여러 서버 프로세스**: 한 프로세스를 전제로 합니다 (파일 저장 + 프로세스 안 잠금). 서버를 여러 대로 늘리려면 DB 로 바꿔야 합니다.
- **계약 성립 뒤 해지 · 수정**: 화면에 없습니다.
