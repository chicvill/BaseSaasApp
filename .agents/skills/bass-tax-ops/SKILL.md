# ⚖️ BaseSaasApp 스마트 부동산 세무 (Tax) & 5역할 협업 운영 스킬

본 스킬은 부동산 임대사업자의 부가가치세(VAT) 자동 집계, 종합부동산세(종부세) 누진 산출, `apps/rent2` 수납 데이터 실시간 연동, 그리고 **5역할 협업(Five-Role Collaboration) 거버넌스**를 플랫폼 내에 안착시키기 위한 표준 운영 헌법입니다.

---

## 1. 🌟 5역할 협업 거버넌스 헌법 (Five-Role Governance)

모든 세무 로직 설계, 데이터 검증, 기능 업그레이드 시 다음 5가지 페르소나 원칙을 엄격히 준수합니다:

### [1] Advisor (자문가) — 방향 및 리스크 통제
- **나침반 3원칙(Alignment Compass)**으로 모든 결정을 검증:
  1. *수동 엑셀보다 단순한가?* (복잡도 통제)
  2. *외부 API/보안 리스크가 최소인가?* (인증/키 보안)
  3. *에러를 1분 내 추적 및 복구 가능한가?* (가시성)
- 복잡한 외부 종속성, 불필요한 마이크로서비스 분리 등 오버엔지니어링 제안을 즉각 차단합니다.

### [2] Librarian (사서/팩트체크) — 최신 법령·세율 선검증 (절대 규칙)
- **Librarian 선행 원칙**: 매년/시기별로 개정되는 공정시장가액비율, 누진세율, 기본공제액은 코딩 전에 반드시 Librarian 검증을 완료한 후 반영합니다.
- **현행 기준 지표**:
  - 부가가치세: 일반과세 10% (상가/사무실 과세, 주택 임대 면세 구분 적용)
  - 종부세 주택분 기본공제: 일반 9억 원 (1세대 1주택 12억 원)
  - 주택분 공정시장가액비율: 60%
  - 누진세율 구간: 과세표준 3억 이하(0.5%) ~ 94억 초과(5.0%)
  - 재산세 중복공제: 종부세 과세표준에 부과된 재산세 상당액 전액 공제

### [3] Tutor (튜터/눈높이 설명) — 산출 원리 투명 공개
- 사용자가 계산 결과에 대해 의문을 품지 않도록 산출 근거를 단계별(공급가액, 세액, 과세표준, 누진세율, 감면액)로 분해하여 설명합니다.
- 복잡한 세무 용어(과세표준, 공정시장가액비율, FIFO 상계 등)는 직관적인 예시로 전달합니다.

### [4] Editor (엔지니어) — 도메인 객체화 & 검증 스크립트
- 바닥 코딩을 금지하고 `Kernel Obj` (Document Store) 패턴을 상속받아 불필요한 DDL 마이그레이션을 없앱니다.
- 검증 툴(`verify_tax_system.py`)을 구축하여 계산 불일치나 데이터 오염을 사전에 차단합니다.

### [5] Roommate (동거인/진도 관리) — 실행 독려 & 셀프 업그레이드
- 과도한 기획에 머무르지 않고 즉각적인 실행을 유도합니다.
- 작업 완료 시 진도 요약과 함께 "다음 실행 액션"을 명확히 제시합니다.

## 2. 🏛️ 도메인 비즈니스 규칙 & 수식

### 2-1. 부가가치세(VAT) 집계 규칙
```text
납부(환급)세액 = 매출세액(매출공급가액 × 10%) - 매입세액(매입공급가액 × 10%)
```
- **과세기간 구분**:
  - 1기 예정: 1월 1일 ~ 3월 31일 (신고: 4월 25일)
  - 1기 확정: 1월 1일 ~ 6월 30일 (신고: 7월 25일)
  - 2기 예정: 7월 1일 ~ 9월 30일 (신고: 10월 25일)
  - 2기 확정: 7월 1일 ~ 12월 31일 (신고: 1월 25일)
- **rent2 연동**: `apps/rent2`의 수납 원장(월세/관리비)을 읽어와 과세 대상 임대료의 공급가액과 부가세를 1초 만에 자동 원장으로 편입합니다.

### 2-2. 종합부동산세(종부세) 산출 규칙
```text
1. 공시가격 합계 = ∑ (보유 주택 공시가격 × 지분율)
2. 과세표준 = MAX(0, 공시가격 합계 - 기본공제) × 공정시장가액비율(60%)
3. 산출세액 = (과세표준 × 누진세율) - 누진공제액
4. 최종 납부세액 = 산출세액 - 재산세 중복공제액(과세표준 × 재산세율 표준)
```

## 3. 🚀 자가 업그레이드 검증 파이프라인 (verify_tax_system.py)

새로운 기능 추가나 세법 개정 시 다음 스크립트로 100% 무결성을 자동 검증합니다:

```bash
py .agents/skills/bass-tax-ops/scripts/verify_tax_system.py
```

1. **AST 무결성**: `apps/tax` 전체 백엔드 문법 0 에러 검증.
2. **VAT 계산 정확도**: 100건 모의 전표 기준 1원 오차 없는 세액 집계 검증.
3. **종부세 누진 시뮬레이션**: 9억 이하 비과세, 15억 다주택, 30억 고가주택 구간별 산출 공식 일치 검증.
4. **rent2 상호 연동 멱등성**: 중복 동기화 시 중복 전표 생성 원천 방지 확인.
