📘 Rent4 사용 설명서

1. Rent4 는 무엇인가요

건물별로, 임대인이 매달 은행 입금 알림 문자를 붙여 넣으면, 문자에서 입금일·금액·입금자를 읽어 호실과 귀속월을 찾아 수납 기록(Knowledge Pool)에 쌓습니다. 임차인은 자기 계정으로 로그인해 입금이 반영됐는지 확인합니다.

2. 로그인과 역할

첫 화면에서 아이디·비밀번호로 로그인하면, 계정에 따라 맞는 화면으로 바로 이동합니다.

역할계정이동하는 화면
관리인플랫폼 최고관리자건물 목록 (시크빌 · 선호아트빌 · 신비주택) → 건물을 고르면 그 건물의 임대인 화면
임대인건물별 관리 계정소속 건물의 임대인 화면 (다른 건물은 볼 수 없음)
임차인건물 코드 + 호실 (예: chic603)내 호실의 입금 확인 화면

3. 계정 · 본인 확인 · 계약

문자는 쓰지 않습니다. 한 번만 쓰는 링크를 대면 · 카카오톡 등으로 전달합니다.

단계누가무엇을
① 계약 발행관리인(가맹) · 임대인(임대차)계약을 작성하면 한 번만 쓰는 계약 시작 링크(24시간)가 나옵니다. 그 자리에서 카카오톡 등으로 보냅니다. 잃어버리면 계약 목록의 🔗 링크로 다시 만듭니다 (이전 링크 무효).
② 비밀번호 설정상대방링크에서 비밀번호를 정하면 바로 로그인되고 링크는 만료됩니다. 다음부터는 휴대폰 번호 + 비밀번호로 들어옵니다.
③ 본인 확인상대방계약 화면에서 카카오 또는 구글로 본인 확인 (서버에 키가 설정된 경우).
④ 계약 동의상대방계약 내용을 보고 동의합니다.
⑤ 납부 확인발행자가맹비 · 잔금 확인 → 체결. 상대방은 로그인 후 ▶ 시작하기 — 최종 아이디(건물 코드 / 코드+호실)에 같은 비밀번호가 넘어갑니다.
  • 로그인: 아이디 또는 휴대폰 번호 + 비밀번호, 또는 본인 확인에 쓴 카카오·구글로 로그인.
  • 아이디 · 비밀번호를 잊었을 때: 로그인 뒤 상단 🔗 구글 연결을 해 둔 분은 로그인 화면의 아이디 찾기 · 비밀번호 찾기(구글 확인 + 이름·전화·부동산)로 스스로 찾습니다. 아니면 임대인에게 비밀번호 초기화를 요청합니다.
  • 대면 계약 마무리 · 임차인 비밀번호 분실: 임대인이 🔑 임차인 계정 탭에서 🔑 비밀번호 초기화 → 이전 비밀번호가 바로 막히고 한 번만 쓰는 링크(24시간)가 나옵니다. 임차인이 Rent4 에 접속해 있으면 화면 오른쪽 아래 💬 채팅창으로 바로 링크가 가고, 접속해 있지 않으면 카카오톡 등으로 보내는 창이 열립니다. 임차인은 링크에서 새 비밀번호를 정하고 바로 로그인합니다. 비밀번호는 암호화(해시)되어 저장되며 임대인도 볼 수 없고, 링크는 쓰는 즉시 만료됩니다.
  • 기존 임차인(Excel 로 등록): 임대인이 🔑 임차인 계정 탭에서 🔑 비밀번호 초기화로 시작 링크를 보내면, 임차인이 링크에서 비밀번호를 정하고 시작합니다.
  • 관리인: 서버 콘솔 py -3.14 scripts/admin_link.py (설정 링크) 또는 scripts/set_password.py admin.

🔒 키 보관 (암호화해서 GitHub 에)

  1. 내 PC 저장소 맨 위에 .env.shared 를 만들고 위 키를 이름=값 으로 한 줄씩 적습니다 (git 제외).
  2. 처음 한 번: py -3.14 shared/core/vault.py newkey → 마스터 키가 .env.key 에 저장됩니다 (git 제외, 화면에 안 나옴).
  3. 서버를 실행하거나 py -3.14 shared/core/vault.py encrypt 를 하면 .env.encrypted 가 새로 암호화됩니다 → 이 파일만 커밋.
  4. 서버(Coolify)에는 .env.key 내용을 환경변수 MASTER_CRYPTO_KEY 하나만 처음 한 번 등록합니다. 이후 키를 바꿔도 서버 설정은 그대로.
  5. 확인: py -3.14 shared/core/vault.py decrypt → 키 이름만 보여 줍니다. 마스터 키는 채팅 · GitHub 에 절대 올리지 않습니다.

4. 임대인 — 입금 문자 반영

  1. 로그인하면 역할에 맞는 화면으로 바로 이동합니다 — 임대인은 자기 건물, 임차인은 자기 호실 (관리인은 가맹점 목록에서 건물을 고릅니다).
  2. 💬 입금 문자 반영 탭에 은행 문자를 그대로 붙여 넣습니다. 여러 건은 빈 줄로 구분합니다.
  3. 🔍 분석하기를 누르면 문자마다 결과가 나옵니다. 이 단계에서는 저장되지 않습니다.
  4. 결과를 확인하고 ✅ 체크한 입금 반영을 누르면 수납 기록에 쌓입니다.
결과뜻할 일
반영 준비호실을 찾았고 금액이 월 청구액(임차료+관리비)의 정확한 배수그대로 반영
금액 확인금액이 월 청구액과 다름귀속월·금액을 확인 후 체크해서 반영
호실 확인입금자명이 세입자와 일치하지 않음 (가족 명의 등)호실을 직접 골라 체크 후 반영
이미 반영됨같은 날짜·시각·금액·입금자의 문자가 이미 반영됨없음 (중복 방지)

귀속월 배정 규칙 (FIFO): 가장 오래된 미납월부터 채웁니다. 미납이 없으면 이번 달, 그다음 달 순입니다. 2개월분을 한 번에 내면 두 달에 나눠 기록합니다.

입금자명에 호실 번호(예: 303호, 김진수303)가 있으면 이름보다 우선해 호실을 찾습니다. 세입자에게 "입금자명에 호실 번호를 넣어 달라"고 안내하면 매칭이 정확해집니다.

규칙으로 금액이나 입금자를 찾지 못한 문자는, 서버에 Gemini AI 키가 설정돼 있으면 AI 가 한 번 더 읽어 보완합니다 (결과에 'AI' 표시).

5. 임대인 — 수납 현황

호실 × 12개월 표입니다. 칸의 숫자는 입금액(만원)과 입금일입니다. 칸을 누르면 상세 내역이 나오고, 입금 문자로 반영한 기록은 반영 취소할 수 있습니다.

  • 초록: 입금 · 테두리 있는 초록: 입금 문자로 반영 · 빨강: 미납 · 노랑: 이번 달 대기
  • 흐린 칸: 현 임차인 입주 전 기록 (이전 임차인) — 임차인 화면에는 보이지 않습니다.
  • ! 표시: 수납부 입금일이 이상하거나 금액이 청구액과 다른 기록

6. 임대인 — Excel 수납부 가져오기

연간 수납부 Excel 에서 제목 행("2026년도")부터 합계 행까지 복사해 붙여 넣습니다. 분석 결과에서 월 합계 대조(시트 하단 합계와 분석 합계 비교)와 확인 필요 항목을 보고 반영합니다.

  • 주민번호 칸은 읽지 않으며 어디에도 저장하지 않습니다.
  • "2. 3", "3-26", "3:16", "1015"(10/15) 같은 입금일 표기를 알아서 읽습니다. "공실·미납·전입·전출" 표기도 보존합니다.
  • 같은 연도를 다시 가져오면 Excel 출처 기록만 교체되고, 입금 문자로 반영한 기록은 그대로 남습니다.

7. 임차인 — 입금 확인

임대인에게 받은 아이디(예: chic603)와 코드로 로그인하고, 처음 한 번 새 비밀번호를 정합니다. 그다음부터는 로그인만 하면 입주한 달부터 이번 달까지 월별로 입금 확인 / 미납 / 이번 달 대기가 표시됩니다. 같은 호실의 이전 임차인 기록과 전화번호는 보이지 않습니다.

8. 데이터 위치

모든 기록은 서버의 data/rent4_pool/ 폴더에 사람이 읽을 수 있는 JSON 으로 저장됩니다 (buildings · rooms · payments · marks · bank_messages · tenant_accounts). 이 폴더는 임차인 개인정보가 있어 git 저장소에 올리지 않습니다.
