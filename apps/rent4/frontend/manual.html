📘 Rent4 사용 설명서

1. Rent4 는 무엇인가요

임대인이 매달 은행 입금 알림 문자를 붙여 넣으면, 문자에서 입금일·금액·입금자를 읽어 호실과 귀속월을 찾아 수납 기록(Knowledge Pool)에 쌓습니다. 임차인은 호실 번호와 휴대폰 뒤 4자리로 자기 입금이 반영됐는지 확인합니다.

2. 임대인 — 입금 문자 반영

  1. 임대인 화면에서 지점 관리자 계정으로 로그인합니다.
  2. 💬 입금 문자 반영 탭에 은행 문자를 그대로 붙여 넣습니다. 여러 건은 빈 줄로 구분합니다.
  3. 🔍 분석하기를 누르면 문자마다 결과가 나옵니다. 이 단계에서는 저장되지 않습니다.
  4. 결과를 확인하고 ✅ 체크한 입금 반영을 누르면 수납 기록에 쌓입니다.
결과뜻할 일
반영 준비호실을 찾았고 금액이 월 청구액(임차료+관리비)의 정확한 배수그대로 반영
금액 확인금액이 월 청구액과 다름귀속월·금액을 확인 후 체크해서 반영
호실 확인입금자명이 세입자와 일치하지 않음 (가족 명의 등)호실을 직접 골라 체크 후 반영
이미 반영됨같은 날짜·시각·금액·입금자의 문자가 이미 반영됨없음 (중복 방지)

귀속월 배정 규칙 (FIFO): 가장 오래된 미납월부터 채웁니다. 미납이 없으면 이번 달, 그다음 달 순입니다. 2개월분을 한 번에 내면 두 달에 나눠 기록합니다.

입금자명에 호실 번호(예: 303호, 김진수303)가 있으면 이름보다 우선해 호실을 찾습니다. 세입자에게 "입금자명에 호실 번호를 넣어 달라"고 안내하면 매칭이 정확해집니다.

규칙으로 금액이나 입금자를 찾지 못한 문자는, 서버에 Gemini AI 키가 설정돼 있으면 AI 가 한 번 더 읽어 보완합니다 (결과에 'AI' 표시).

3. 임대인 — 수납 현황

호실 × 12개월 표입니다. 칸의 숫자는 입금액(만원)과 입금일입니다. 칸을 누르면 상세 내역이 나오고, 입금 문자로 반영한 기록은 반영 취소할 수 있습니다.

  • 초록: 입금 · 테두리 있는 초록: 입금 문자로 반영 · 빨강: 미납 · 노랑: 이번 달 대기
  • 흐린 칸: 현 임차인 입주 전 기록 (이전 임차인) — 임차인 화면에는 보이지 않습니다.
  • ! 표시: 수납부 입금일이 이상하거나 금액이 청구액과 다른 기록

4. 임대인 — Excel 수납부 가져오기

연간 수납부 Excel 에서 제목 행("2026년도")부터 합계 행까지 복사해 붙여 넣습니다. 분석 결과에서 월 합계 대조(시트 하단 합계와 분석 합계 비교)와 확인 필요 항목을 보고 반영합니다.

  • 주민번호 칸은 읽지 않으며 어디에도 저장하지 않습니다.
  • "2. 3", "3-26", "3:16", "1015"(10/15) 같은 입금일 표기를 알아서 읽습니다. "공실·미납·전입·전출" 표기도 보존합니다.
  • 같은 연도를 다시 가져오면 Excel 출처 기록만 교체되고, 입금 문자로 반영한 기록은 그대로 남습니다.

5. 임차인 — 입금 확인

호실 번호와 계약 때 등록한 휴대폰 번호 뒤 4자리를 입력합니다. 입주한 달부터 이번 달까지 월별로 입금 확인 / 미납 / 이번 달 대기가 표시됩니다. 확인 실패가 10분 안에 5번 반복되면 잠시 조회가 막힙니다.

6. 데이터 위치

모든 기록은 서버의 data/rent4_pool/ 폴더에 사람이 읽을 수 있는 JSON 으로 저장됩니다 (rooms · payments · marks · bank_messages). 이 폴더는 임차인 개인정보가 있어 git 저장소에 올리지 않습니다.
