1. 🏡 OpenRent 벤치마킹 직거래 포털 개요 (/rent3/index.html)

핵심 구조 영국 직거래 표준 플랫폼 OpenRent(openrent.co.uk)의 사용자 경험을 한국 임대차 및 공동 실시간 Data Pool(data/rent3_pool/*.json)에 최적화하여 구성했습니다.
  • 통합 매물 검색 & 퀵 필터: 지역·건물명·옵션 검색, 즉시입주, 만기전출 예정 사전공개, 등기 근저당 0원 클린 필터 제공.
  • 월세 부담능력 계산기 (Affordability Calculator): 월 세후 소득 30% 기준 권장 주거비 및 보유 보증금 이내 매물 자동 필터링.
  • No Dead Listings 실시간 연동: rooms.json과 직결되어 계약 체결 즉시 매물이 마감되고, 퇴실·만기전출 시 자동 게시됩니다.

2. 🔐 로그인 후 역할별 자동 페이지 분기 규칙

상단 [🔐 로그인 / 회원가입 (Sign In)] 모달에서 로그인하면 서버(POST /api/rent3/pool/auth/login)가 계정 역할을 판별해 알맞은 전용 워크스페이스로 즉시 이동시킵니다.

사용자 역할 로그인 식별자 예시 자동 이동 페이지 (Redirect URL) 주요 수행 기능
👑 총괄 관리인 admin (PW: 1212) /rent3_admin/
(옵션 선택 시 /rent3/pool.html)		 임대인 가맹 승인, 월 SaaS 이용료 정산, 전 지점 NOI 수익률, RTMS 감시

3. 🔄 실시간 공동 JSON Data Pool 무결성 원칙

  • 원자적 동기화: 5개 분리 앱(rent3, rent3_admin, rent3_lessor, rent3_tenant, rent3_contract)이 하나의 data/rent3_pool/*.json을 실시간으로 공유합니다.
  • 법적 안전 불변식: 거래 건당 중개수수료(복비) 0원 원칙, 주택임대차보호법 제6·7조(만기 6~2개월 전출확인 및 5% 증액 상한), 후불 입주월 가짜체납 방지 원칙을 준수합니다.
