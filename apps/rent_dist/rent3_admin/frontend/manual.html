2. 임대인 가맹 심사 (등기부 & 사업자등록증 홈택스 확인·승인) 절차

  1. 등기부 원본 확인 (인터넷등기소): 임대인이 가맹 신청 시 올린 등기부의 AI 추출 발급확인번호를 복사해 [인터넷등기소 열기 ↗]에서 조회한 뒤, 소유자·소재지·근저당 일치 여부를 [📝 원본 대조 결과 기록]으로 남깁니다.
  2. 사업자등록증 확인·승인 (국세청 홈택스): 임대인이 [📷 촬영하기] 또는 [🖼 사진·PDF 선택]으로 제출한 사업자등록증(세금계산서 수신용 이메일·업태·종목 포함)의 10자리 국세청 체크섬·AI 추출 대표자 성명 대조 결과와 [사업자등록증 원본 보기]를 확인합니다.
  3. [사업자번호 복사] → [국세청 홈택스 열기 ↗]에서 사업자 상태가 정상 계속사업자인지 확인한 후 [✅ 홈택스 확인·승인 기록]을 누르면, 임대인 장부의 공식 business_number로 확정되며 지원 채팅으로 승인 알림이 발송됩니다(휴·폐업, 번호 오류, 다른 임대인이 이미 승인받은 중복 사업자번호는 승인 차단).

3. 관리인 → 임대인 암호 설정 링크 발급 및 6개월 변경 권유

  1. 최초/재설정 링크 발급: [🛟 운영 안전 · 백업 · 계정] 탭에서 전화로 본인 확인을 마친 임대인을 선택하고 [🔑 임대인 암호 설정 링크 발급]을 누릅니다(장부에 승인된 사업자번호 또는 계좌번호 끝 4자리 이상이 있어야 발급 가능).
  2. 4칸 본인확인 후 암호 설정: 임대인은 전달받은 1회용 링크(7일 유효)를 열어 건물명 · 본인 이름 · 전화번호 · 사업자등록번호(또는 계좌번호) 끝 4자리 이상 4칸을 통과해야 새 비밀번호를 설정할 수 있습니다.
  3. 6개월(180일) 정기 변경 권유: 비밀번호 변경 후 180일이 지난 임대인은 목록에 ⚠️ 6개월 경과 권유 대상으로 표시됩니다. [🔒 6개월 새 암호 설정 권유 발송]을 누르면 지원 채팅과 문자로 권유 링크가 전달되며, 임대인이 새 비밀번호를 설정하기 전까지 기존 비밀번호와 등록 기기는 그대로 유지됩니다.

4. 관리인 → 임대인 월 가맹비 징수 · 세금계산서 및 현금영수증 발급 과정

  1. 월 가맹비 청구·통보: [🏢 임대인 가맹 · 월 가맹비] 탭 상단에서 [이번 달 청구·통보 만들기]를 누르면(또는 RENT3_FEE_AUTO=1 자동 모드), 가맹 승인된 임대인별로 월 이용료(공급가액 + 부가세 10%, 납부기한 매월 10일) 청구가 생성되고 지원 채팅으로 통보됩니다.
  2. 입금 확인 및 납부 등록: 임대인이 가맹비를 입금하면 해당 청구 행의 [💰 납부 등록]을 눌러 입금일·금액(청구액과 일치 필수)·결제수단을 기록합니다.
  3. 세금계산서 또는 현금영수증 발급 (임대인 사업자번호 유무에 따라 자동 분기):
    • ① [📋 발급 정보 · 홈택스] 공용 카드 (기본 수동 발급 루틴): 청구 행의 [📋 발급 정보 · 홈택스]를 누르면 공급자(플랫폼)와 공급받는자(임대인)의 사업자번호·상호·대표자·주소·업태·종목·이메일·공급가액·세액이 항목별 [복사](숫자는 쉼표 제외) 및 [📋 전체 복사]와 함께 표시됩니다. [🏛️ 홈택스 열기 ↗]로 홈택스에서 발급한 뒤, 같은 창 안의 [✍️ 발급했어요 — 승인번호 기록]을 눌러 국세청 24자리 승인번호를 기록합니다.
    • ② 사업자등록번호가 없는 임대인 → 💵 현금영수증 발급: 임대인에게 승인된 사업자등록번호가 없으면 세금계산서 탭이 비활성화되고 [💵 현금영수증] 탭(휴대폰 번호 기준 소득공제용, 사업자번호가 있으면 지출증빙용도 선택 가능)이 열립니다. 홈택스에서 현금영수증을 발급한 뒤 [✍️ 현금영수증 발급했어요 — 승인번호 기록]을 눌러 승인번호(숫자 6~12자리)를 기록합니다.
    • ③ 볼타(Bolta) API 자동/즉시 발행 (선택 연동): 서버에 RENT3_ETAX_PROVIDER=bolta가 설정된 경우 납부 등록 즉시(RENT3_ETAX_AUTO=1) 또는 [🧾 API로 발행] 버튼으로 전자세금계산서를 접수하고 웹훅/조회 API(ntsTransactionId)로 24자리 승인번호를 자동 확정합니다(응답 불확실 시 이중 발행 방지를 위해 재전송을 막고 [🔄 발행 상태 확인]으로만 조회).
  4. 임대인 장부 경비 자동 반영 (세금계산서 vs 현금영수증 구분):
    • 전자세금계산서(24자리 승인번호) 기록 시: 임대인 지출 장부(outlays.json)에 evidence_type="TAX_INVOICE"(부가세 매입세액 공제 가능 + 종소세 필요경비)로 자동 등재됩니다.
    • 현금영수증(6~12자리 승인번호) 기록 시: 임대인 지출 장부에 evidence_type="CASH_RECEIPT", 부가세 매입세액 불공제(vat_deductible=False)로 등재되어 5월 종합소득세 필요경비 증빙으로만 정확히 반영됩니다.
